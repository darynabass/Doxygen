Smart Noter Bot is a Telegram bot for managing personal notes, reminders, and custom lists. It also provides activity statistics and sends scheduled reminders in the background.\hypertarget{index_autotoc_md1}{}\doxysection{\texorpdfstring{Features}{Features}}\label{index_autotoc_md1}

\begin{DoxyItemize}
\item Create and manage notes
\item Create reminders and choose their priority
\item Create and view custom lists
\item Edit item text, priority, and reminder schedule
\item Mark reminders as completed
\item View user activity statistics
\item Send scheduled reminders in the background
\end{DoxyItemize}\hypertarget{index_autotoc_md2}{}\doxysection{\texorpdfstring{Tech Stack}{Tech Stack}}\label{index_autotoc_md2}

\begin{DoxyItemize}
\item {\bfseries{Python 3.\+10+}}
\item {\bfseries{aiogram 3.\+x}} — asynchronous framework for the Telegram Bot API
\item {\bfseries{aiosqlite}} — asynchronous interface for SQLite
\item {\bfseries{python-\/dotenv}} — loads environment variables from a {\ttfamily .env} file
\item {\bfseries{SQLite}} — database
\end{DoxyItemize}\hypertarget{index_autotoc_md3}{}\doxysection{\texorpdfstring{Requirements}{Requirements}}\label{index_autotoc_md3}

\begin{DoxyItemize}
